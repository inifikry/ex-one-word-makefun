# Describe Your Ex in One Word

Entry for make.fun's "Describe Your Ex in One Word" bounty.

The entry is one word: **Unsubscribed** — the ex as a subscription
you finally cancelled. A verdict, not an insult: the relationship
ended the way a newsletter does, with one click and no reply-all.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (12 characters, no trailing
newline). Deterministic: no network, no randomness, no time dependence.
